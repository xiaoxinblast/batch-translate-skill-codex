# 日中翻译注意事项（附正反示例）

> 用途：生成 `batch_translate/data/style_guide.txt` 时，必须把本节完整内容写入风格指南（标题 + 十项规则 + 正反示例），确保每个新项目的风格指南都包含这部分。

## 1. 主语/人称代词补充

日语常省略主语，中文须视上下文补出，避免读者不知所指。

- 正例：彼は来ると言った。→ 他说他会来。
- 误例：来ると言った。→ 说会来。（谁说的？）

## 2. 汉字词转换

日文中的汉字词不能直接照搬，须换为中文固有说法。

- 正例：検討 → 研究（而非"检讨"）
- 正例：対応 → 处理（而非"对应"）
- 正例：情報 → 情报（中文"信息"更自然时改用"信息"）
- 误例：事件の検討を行う → 进行事件的检讨

## 3. 语序调整

日语 SOV → 中文 SVO，宾语、补语位置须重组。

- 正例：ご飯を食べる → 吃饭
- 正例：彼に本をあげた → 我把书给了他
- 误例：飯を食う → 饭吃了

## 4. 被动转主动

日语惯用被动表达，中文多数情况须转为主动句。

- 正例：先生に褒められた → 老师表扬了我
- 误例：我被老师表扬了（多数语境下不自然）

## 5. 长句拆分

日语的连用形可串起多个从句，中文须切成短句、层次分明。

- 正例：街に出て買い物をして帰ってきた → 我上街买了东西，然后回来了
- 误例：上街购物然后回来了（一长串不拆分）

## 6. 长定语后置

日语的连体修饰语可极长，中文的前置定语须精简或后置。

- 正例：昨日買った赤いかばん → 昨天买的红色包包
- 定语过长时拆分：那个红色包包，是昨天买的
- 误例：我昨天在车站前面的那家百货商店里跟朋友一起挑选了很久之后买的那个红色的包包

## 7. 暧昧表达去/留

日语好「～と思われる」「～ようだ」，中文视文本类型决定是否保留推测语气。

- 正例（剧情对话）：彼は来ないようだ → 看来他不会来了
- 正例（说明文）：効果があると思われる → 有显著效果（去掉推测语气）
- 误例（说明文）：似乎有效果（过于暧昧）

## 8. 指示词具体化

日语的「これ/それ/あれ」尽量还原为具体名词，避免中文满篇"这个""那个"。

- 正例：それは危険だ → 那个敌人很危险
- 正例：これを使え → 用这个回复剂
- 误例：それは危険だ → 那个很危险

## 9. 敬语落差弥合

日语敬语体系（尊敬/謙譲/丁寧）在中文中无对等物，须靠措辞（"您""在下""请"）和语气弥合身份差。

- 正例：申し訳ございません → 非常抱歉
- 正例：なにやってんだよ！（粗鲁语气）→ 你在干什么啊！
- 注意：设定中使用古语/敬语的角色群体，中文可用"您""请"等体现身份差

## 10. 性别人称代词核实

日文人称代词或省略的主语不直接决定中文应使用“他”“她”或“它”。使用有性别人称代词前，必须先根据任务上下文、项目文件（角色资料、说话人、注释、术语库或 TM）确认角色身份；项目资料不足时，可查询可核验的公开资料后再决定。

- 正例：角色资料确认アクア为女性。→ 她正在修行。
- 正例：角色身份无法确认。→ 先询问过艾拉库斯大师的意见。（以姓名或称谓避开代词）
- 误例：角色身份不明。→ 他已经同意了。（把“他”当作默认代词）
